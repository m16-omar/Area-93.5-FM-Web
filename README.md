# 📻 93.5 Area FM Web — "One Voice, Every Area"

Official web application for **Area 93.5 FM**, Lagos' premier urban radio station broadcasting high-energy afrobeats, talk shows, charts, podcasts, and community news.

---

## 🌟 Key Features

- **Live Streaming Audio Player**: Persistent, non-stop HLS/MP3 live radio streaming player with volume control and on-air indicator.
- **Weekly Shows Schedule (`/shows`)**:
  - Hero with dark DJ atmosphere and brand red arch accents.
  - Continuous 2-card auto-sliding stream for today's broadcasts.
  - Continuous 3-card auto-sliding carousel for station hosts and presenters.
  - Interactive day-by-day weekly show directory.
- **Presenter & Host Profiles (`/hosts` & `/hosts/:slug`)**:
  - Full Nigerian presenter lineup with rich bios, assigned shows, contact info, and social links.
- **News & Editorial Magazine (`/news`)**:
  - 16:9 post stream with category tags, interactive search, and live on-air widget.
- **Podcasts & Catch-Up (`/podcasts`)**:
  - On-demand audio episodes, chart countdowns, and featured interviews.
- **Charts & Countdown (`/charts`)**:
  - Top Nigerian afrobeats & street hit rankings.
- **Studio Contacts & Advertising (`/contact` & `/promote`)**:
  - Direct booking, rate cards, interactive inquiry forms, and studio location in Ikeja, Lagos.

---

## 🚀 Tech Stack

- **Framework**: React 19 + Vite 6
- **Routing**: React Router v7
- **Styling**: Vanilla CSS Modules (Glassmorphism, custom brand tokens)
- **Animations**: Framer Motion
- **Icons**: React Icons (Lucide, FontAwesome 6, Simple Icons)

## 🛠️ Getting Started

```bash
# Clone the repository
git clone git@github.com:m16-omar/Area-93.5-FM-Web.git

# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production
npm run build
```
