# Contributing to Area 93.5 FM Web

Thank you for your interest in contributing to the **93.5 Area FM Web** project!

---

## 📻 Contribution Guidelines

1. **Branch Naming Conventions**:
   - `feature/<feature-name>`: For new modules, UI sections, or pages.
   - `fix/<bug-name>`: For bug fixes and responsive layout corrections.
   - `docs/<doc-name>`: For documentation and asset updates.

2. **Code Standards**:
   - Ensure all components follow standard React structure.
   - Use CSS Modules with pre-defined brand color tokens (`#006B8D`, `#004E68`, `#E50914`, `#EAF3F7`).
   - Use authentic Nigerian names and studio address for local context.

3. **Submitting Changes**:
   - Create a branch from `main`.
   - Run `npm run build` to verify that there are zero compile errors.
   - Open a Pull Request on GitHub with a concise summary of changes.
